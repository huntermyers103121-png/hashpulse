# HashPulse

Live Bitcoin mining dashboard: hashprice, difficulty, hashrate, and pool shares.

This is **not** a cloud miner. It does not generate Bitcoin. It reads public data from [mempool.space](https://mempool.space/docs/api/rest).

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy

Push to GitHub and import the repo in Vercel (Next.js).
